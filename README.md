# Study

تطبيق Study للدراسة، من تطوير هشام السنوسي. يعمل بدون إنترنت بالكامل.

## الحصول على ملف APK

1. افتح تبويب **Actions** في المستودع وانتظر اكتمال تشغيل **Build APK**.
2. نزّل الملف `Study.apk` من قسم **Artifacts**، أو من صفحة **Releases** (الوسم `latest-apk`).
3. على الهاتف: فعّل «التثبيت من مصادر غير معروفة» ثم ثبّت الملف.

لإعادة البناء يدوياً: Actions ثم Build APK ثم Run workflow.

## تعديل التطبيق

التطبيق صفحة واحدة في `www/index.html`. أي تعديل عليها ثم الدفع إلى الفرع الرئيسي يبني APK جديداً تلقائياً.
